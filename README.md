# Сайт турклубу КПІ «Глобус» — прототип

Прототип нового сайту турклубу «Глобус». Офіційний сайт клубу — https://www.tkg.org.ua.

- Сайт: https://tk-globus.pages.dev (не індексується пошуковиками)
- Стек: Astro + Tailwind CSS, хостинг Cloudflare Pages
- Інструкція для розробки (і для ШІ-агентів): [AGENTS.md](AGENTS.md)

```sh
npm install
npm run dev     # http://localhost:4321
npm run check   # усі перевірки, як у CI
```
